# Orielis v0.3.1 — نسخهٔ آمادهٔ تست

این نسخه از فایل منتشرشدهٔ v0.3.0 در مخزن
https://github.com/noroozihossein/home-assistant-orielis-universal
ساخته شده است؛ اصلاحات آزمایشی حساسیت و زمان‌بندی نسخه‌های beta مبنا نیستند.

## تغییرات

- در هر کانال سبز، Light minimum brightness و Light maximum brightness اضافه شده‌اند. پیش‌فرض ۱ و ۱۰۰ درصد است.
- محدوده برای تمام چراغ‌های انتخاب‌شدهٔ همان کانال اعمال می‌شود. این دو گزینه به‌ازای کانال هستند، نه برای هر عضو آن به‌صورت جداگانه.
- چرخش شدت نور را در محدوده نگه می‌دارد و فرمان روشنایی صفر نمی‌فرستد. خاموش‌کردن با فرمان off دکمه باقی مانده است.
- حالت Synchronized سطح یکسانی را از چراغ مرجع محاسبه می‌کند؛ Relative برای هر چراغ از مقدار خودش محاسبه می‌کند.
- محدوده مخصوص تغییر شدت نور توسط بلوپرینت است؛ تغییر دستی از داشبورد یا اکشن دلخواه تابع آن نیست.
- چراغ خاموش طبق رفتار قبلی با چرخش روشن نمی‌شود، مگر گزینهٔ Rotation may turn on an off light فعال باشد.
- حالت آبی برای اتومیشن جدید پیش‌فرض Curtains / blinds دارد. کنترل خودکار روشنایی و گزینه‌های CCT و گام دیمر از منوی آبی حذف شده‌اند.
- صوت، پرده، تنظیم دمای سیستم، کنترل عددی و Custom actions در آبی حفظ شده‌اند. اکشن دلخواه می‌تواند هر فرمان Home Assistant را اجرا کند.
- در آبی، Secondary فقط برای قبلی/بعدی موسیقی است؛ فرمان مستقل CCT از سخت‌افزار این حالت دریافت نمی‌شود.
- حالت قرمز، تریگرها، cooldown و حالت اجرای single نسبت به نسخهٔ مبنا تغییر نکرده‌اند.
- شناسهٔ ثابت دستگاه یا Zigbee Group ID اضافه نشده است.

## نصب

۱. از YAML فعلی نسخهٔ پشتیبان بگیر و فایل mrsmart_orielis_universal.yaml این بسته را دقیقاً جای همان فایل بلوپرینت قبلی قرار بده.
۲. اتومیشن آزمایشی قبلی این ریموت را غیرفعال کن تا دو اتومیشن هم‌زمان فرمان ندهند.
۳. اتومیشن‌ها را Reload کن و صفحهٔ ویرایش را دوباره باز کن؛ عنوان باید v0.3.1 باشد.
۴. در کانال سبز حداقل و حداکثر را وارد کن؛ مثلاً ۱۰ و ۸۰ درصد.
۵. اگر آبی از قبل برای چراغ تنظیم شده، چراغ‌ها را به سبز منتقل کن. برای آبی Control type را صریحاً روی پرده، صوت یا Custom تنظیم کن؛ مقدار ذخیره‌شدهٔ اتومیشن قبلی الزاماً با پیش‌فرض جدید جایگزین نمی‌شود.
۶. فقط یک اتومیشن فعال برای هر ریموت نگه دار.

درصدها به مقیاس صحیح ۱ تا ۲۵۵ تبدیل می‌شوند؛ نمایش UI ممکن است گرد شود. اگر حداقل و حداکثر برعکس وارد شوند، کد آن‌ها را مرتب می‌کند. اگر برابر باشند، نزدیک‌ترین مقدار قابل‌نمایشِ حد پایین استفاده می‌شود.

این نسخه تست نرم‌افزاری شده است؛ تأیید عملکرد فیزیکی این آپدیت روی ریموت و تجهیزات هنوز باقی است.
